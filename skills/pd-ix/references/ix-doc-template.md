# .ix.md 模板

Step 3 产出 `.ix.md` 时使用此模板。

```markdown
# 设计: {title}
> 状态: 草稿
> 作者: {username}
> 日期: {yymmdd}
> PRD: {.prd.md 路径, 无则 "N/A"}
> 保真度: 低保真 / 中保真 / 高保真
> 设计源: [design-source: claude-design <projectId>] / [design-source: taste-skill <skill 名>] / ...

## 竞品参考
| 竞品 | 关键页/功能 | 文字说明 | HTML 要点 | 截图 | 值得借鉴的 | 不想要的 |
|---|---|---|---|---|---|---|

## 现状
[已有产品相关页面截图/描述; 全新产品则列可复用的视觉资产]

## 信息架构
[页面/视图清单 + 层级 + 导航结构 + 每页包含哪些交互]

## 交互拆解

### 订单.P1.1: 浏览商品列表

**竞品做法**
- [SOURCE: url] 竞品A: 瀑布流 + 筛选栏左侧固定
- [SOURCE: url] 竞品B: 卡片网格 + 顶部标签筛选

**设计决策**
[我们怎么做 + 为什么（引用竞品 + PRD 约束）]

**线框图**
[ASCII/文字版布局: 区块划分 + 内容清单]

**状态覆盖**
| 状态 | 表现 |
|---|---|
| 正常 | 商品列表正常展示 |
| empty | "暂无商品" + 引导 |
| loading | 骨架屏 |
| error | 加载失败 + 重试 |

### 订单.P1.2: 查看商品详情
[同上四块结构: 竞品做法 / 设计决策 / 线框图 / 状态覆盖]

### ...更多交互（每条 PRD 路径拆出的每个交互点）

## 视觉方向
[选定方向描述; 中/高保真填具体值: 配色 token / 字号字重 / 间距 / 圆角]

## 设计系统补齐（claude-design 时）
[缺口清单 + 补齐的组件列表 + projectId]

## 原型
[高保真档: prototype.html 路径 / claude-design patterns 路径 + 截图说明; 否则 "N/A — 低保真，未出原型"]

## PRD 路径覆盖
[逐条使用路径 + 系统路径 → 对应界面/交互流, 确认无遗漏。pd-ix 阶段按交互拆解核对填状态；进入 pd-vd 后以 `.vd.md` 的验证记录为准]
| 路径 | 对应界面/流程 | 状态 |
|---|---|---|
| 订单.P1 | 见上方交互流 | ✅ |
| 系统.1 (支付回调) | 支付等待页→成功/失败状态切换 | ✅ (用户可见部分) |

> 验证记录（页面/交互覆盖矩阵、PRD 路径走查、vis-review Report）由 pd-vd Step 5c/5d/5e 产出，落 `.vd.md` 的 `## 验证记录` 节（pd-vd Step 5f），不在本文档。

## 待定项
- [TBD] 问题 1
```
