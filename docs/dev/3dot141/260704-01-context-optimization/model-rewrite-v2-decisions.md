## 汇总处置原则

1. **两路交集的项（高置信）**：无条件恢复，不需要再讨论。
2. **单路命中但证据可机械核实的项（如"终点skill完成报告"分支、`docs/nocode/prds`）**：直接 Read 原文确认后恢复，不因为"只有一路说"就打折扣。
3. **单路命中且属于判断类分歧（如语气规范整节的严重度）**：采信更保守的一方（即认为"应该保留"的一方），因为这类内容此前已经证明我自己的"零价值"判断经常是错的（语气规范这次就是实例）。
4. **两路都沉默的项（如硬护栏具体命令清单）**：维持原重写决定，这是目前唯一有正面证据支持"删除安全"的一类。
5. 不在本次重写里顺手"纠正"原文件自身可能已存在的过期错误（如 /distill 的"五出口"疑似应为"七出口"）——那是另一个独立问题，混进来会让这次"内容保真"的重写目标复杂化，单独记录留给用户决定要不要处理。
