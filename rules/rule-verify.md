# nocode-evolve:verify 独立触发

devflow 外部独立触发 verify skill 的约束。

## 触发条件

用户说「验证一下 / 跑一下看看 / 确认能用 / verify / 测一下整体」，或 Build 完成后需要端到端验证。

## 做法

1. 确认 Build 已完成（测试通过 + build 通过）
2. `Skill(nocode-evolve:verify)` — 走完整验证流程
3. 证据收集 → 集成测试 → E2E → 性能 → 验收核对

## 关键约束

- **Iron Law**: 无新鲜证据不得宣称完成
- "跳任一步 = 撒谎"
- "看起来对"不是证据——跑一遍才是
- 验收标准逐条核对，每条附证据

## 不要

- 不声称"已经验证了"而没有实际跑命令
- 不跳过 e2e（有 UI 时）或集成测试
- 验证失败不硬过——回 Build 修复
